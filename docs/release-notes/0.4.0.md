# Simple Glossary 0.4.0 — release notes

## Now works on mobile

Simple Glossary now runs on Obsidian for iPhone, iPad and Android, as well as on desktop.

- **Tap** a marked term to show its tooltip. Tap it again, or anywhere else, to close it.
- **Open in glossary** in the tooltip goes to the entry. In Reading view a tap shows the tooltip instead of opening the glossary.
- A term written as a link, such as `[[SYMCA]]`, still opens its note when tapped.
- While editing, tapping a term also places the cursor, as usual.
- The tooltip fits a narrow screen, and its links are easier to tap.
- **Add a term to the glossary** works on mobile too. Run it from the command palette, or add it to the toolbar in Settings → Mobile. On a phone, the term and description boxes stack one above the other.

Nothing changes on desktop.
