# Simple Glossary 0.2.0 — release notes

## New: add a term without opening the glossary

**Add a term to the glossary** is a new command that opens a small window with a box for the term and a box for what it means.

- **Enter** saves and **Escape** cancels.
- If you have text selected in a note when you run the command, it is filled in as the term.
- If the term is already in the glossary, in any combination of capitals, the window tells you as you type and won't save it.
- A term can be up to 40 characters, and can't contain any of these characters: `` : * _ ` [ ] # | < > ``. These characters would stop the plugin reading it back as a term. Terms like `CI/CD`, `C++`, `R&D` and `5G` are fine.
- If the glossary note doesn't exist yet, it is created.

The command has no hotkey to start with. Give it one in **Settings → Hotkeys**: search for "Simple Glossary".

## The glossary stays sorted

The new term is added as a plain list item, `- TERM: what it means`. The glossary's list is then sorted A–Z by the term alone:

- Bold, links, `[[…]]` and capitals are ignored, and numbers sort as numbers (5G before 10G).
- If the glossary has lists under separate headings, each list is sorted on its own, and the new term goes into the longest list.
- Lines indented under an entry move with it.
- Each list keeps a single bullet style, and numbered lists are renumbered, so a stray `1.` among `-` items doesn't split the list in two.

Headings, text and everything else in the note stay where they are.

## Privacy

This is the first version of Simple Glossary that writes to a note. It writes only to your glossary note, and only when you press Save in the new window. It still makes no network requests, and it doesn't change any other note.
