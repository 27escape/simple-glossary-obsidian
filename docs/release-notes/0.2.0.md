# Simple Glossary 0.2.0 — release notes

## New: add a term without opening the glossary

- **Add a term to the glossary** is a new command. Give it a hotkey in Settings → Hotkeys. It opens a small window with the term and what it means. Enter saves and Escape cancels.
- If you have text selected in a note, it becomes the term.
- If the term is already in the glossary, the window tells you and doesn't save it.
- The entry is added as `- **TERM**: what it means`, and the glossary's list is then sorted A–Z by term, ignoring bold, links and upper or lower case.
- If the glossary has more than one list, for example under separate headings, each is sorted on its own.
- Lines indented under an entry move with it.
- Each list gets one bullet style, and numbered lists are renumbered.

## Privacy

This is the first time Simple Glossary writes to a note. It writes only to your glossary note, and only when you save a new term. It still makes no network requests.
