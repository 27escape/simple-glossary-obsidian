# Simple Glossary 0.3.0 — release notes

## New: terms that match in any case

Start a term with `^` in your glossary to have it match whatever its capitals:

```markdown
- ^socitm: Society for Innovation, Technology and Modernisation
```

This one entry matches "socitm", "Socitm" and "SOCITM", so you no longer need an entry for each spelling.

- Every other term still follows the **Match case** setting. With that setting off, every term matches in any case anyway, so `^` makes no difference.
- The `^` isn't shown in the tooltip.
- It works for bold and linked terms too, for example `**^socitm**` or `[[^socitm]]`.
- Sorting and duplicate checks ignore the `^`, so `^socitm` sorts under S and counts as the same term as `Socitm`.
- If the glossary has both `Socitm` and `^socitm`, text written exactly "Socitm" gets the `Socitm` entry. Any other spelling gets the `^socitm` entry.
- In the **Add to glossary** window, start the term with `^` in the same way. The window now shows a one-line reminder of this.
