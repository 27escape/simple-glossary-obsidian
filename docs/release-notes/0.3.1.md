# Simple Glossary 0.3.1 — release notes

## Open the glossary from the Add to glossary window

The **Add to glossary** window now has an **Open glossary** link on the left, opposite Cancel and Save. It closes the window and opens your glossary note in a new tab, so you can check or edit an entry without going through the command palette.

If no glossary note is chosen yet, or the chosen note doesn't exist, the window says so instead.
